# KB AI DevOps Study Buddy

An AI-powered interview preparation and learning assistant built using:

- Python
- Streamlit
- Amazon Bedrock
- JSON Storage

---

## Features

- Study Plan Generator
- AI Study Plan Generator
- Interview Question Generator
- AI Interview Question Generator
- Answer Evaluation
- AI Answer Evaluation
- Progress Tracking
- Weak Topic Tracking
- Learning Path Generator
- Evaluation History
- Bedrock Usage Dashboard
